# 黑白點方陣

用小鳥當線索的數字推理遊戲。每一列、每一行都要填入 1 到 N，格子之間的小鳥告訴你相鄰兩格的關係。

## 玩法

- **闖關**：8 章 100 關，每章登場一隻新鳥、帶來一條新規則，越後面越難。所有關卡都可以直接從「選關」挑著玩。
- **每日一題**：每天（台北時間）一題，週末是 9×9 大盤，記錄連續天數。
- **自由練習**：自選大小、難度和要出現的鳥。
- 鳥類圖鑑、鳥園、成就；提示會說明推理的原因。
- 筆記有兩種：「筆記」記下可能的數字，「排除」把不可能的數字劃掉。
- 外觀可以切換「自動（跟著手機）／淺色／深色」。

| 鳥 | 規則 |
|---|---|
| 玄鳳鸚鵡 | 兩格相差 1（全部畫出） |
| 青背山雀 | 一格是另一格的兩倍（全部畫出） |
| 綠繡眼 | 兩格相加 = N+1 |
| 翠鳥 | 兩格相差 2 |
| 麻雀 | 兩格同為奇數或同為偶數 |
| 領角鴞 | 站在四格交界，數字是四格總和 |
| 台灣藍鵲 | 兩格相差 3 |
| 五色鳥 | 一格是另一格的三倍 |

## 執行

整個遊戲是一個 `index.html`，直接用瀏覽器打開就能玩，不需要安裝任何東西。進度存在各自瀏覽器的本機儲存空間。

## 修改

原始碼在 `src/`，改完後執行：

```
python3 build.py
```

會重新產生 `index.html`。背景森林由 `tools/make_scenery.py` 產生（輸出到 `src/scenery.html`）。
